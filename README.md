# LoL Guessing Game

LoL Guessing Game is a web application that challenges players to see how many champions from League of Legends they can name from memory. Users enter champion names one at a time, and the application tracks their progress against the complete champion roster.

The idea for this project came from a simple question: how many League of Legends champions can the average player actually remember without looking anything up? Instead of keeping track on paper, I decided to build a website that could automatically validate guesses, track scores, and provide an interactive experience for other players.
